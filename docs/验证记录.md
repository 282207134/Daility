## 复现

```bash
flutter analyze
flutter test
flutter drive \
  --driver=test_driver/integration_test.dart \
  --target=integration_test/app_flow_test.dart \
  -d emulator-5554
flutter build apk --release
flutter build web
```

模拟器名称或设备 ID 不同时，用 `flutter devices` 返回的 ID 替换。测试脚本没有依赖在线接口，也不需要登录账号。
